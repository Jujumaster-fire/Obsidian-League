# How to apply new database schemas in Supabase

1. Log in to your Supabase account and go to your **Dashboard**.
2. Select your Obsidian Elite project.
3. On the left-hand sidebar, click on **SQL Editor** (it looks like a terminal/code icon `>_`).
4. Click on **New query**.
5. Open the `supabase/schema_updates.sql` file in this codebase, select all the text inside it, and **Copy** it.
6. Paste the copied SQL text into the Supabase query editor.
7. Click the **Run** button (usually in the bottom right or top right).
8. If it says "Success", your database has been updated with the new columns and tables required for the new features!
